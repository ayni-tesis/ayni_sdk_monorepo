## Nodos

Un workflow combina estos nodos:

- **Entrada de imagen:** la imagen que la app entrega al workflow.
- **Modelo:** una versión de un modelo TensorFlow Lite que clasifica la imagen,
  detecta objetos en ella o segmenta sus píxeles.
- **Condición:** compara la confianza de una clasificación, o el porcentaje de
  área de una etiqueta de una segmentación, con un umbral y sigue la rama
  verdadera o la falsa.
- **Salida:** el resultado con nombre que recibe la app.

## Reglas

- Un workflow pertenece a una sola aplicación.
- Se diseña como borrador en el lienzo del dashboard, que solo editan los
  administradores.
- Un borrador necesita un nodo de entrada de imagen y al menos un nodo de
  salida, y no admite ciclos.
- Solo se publica un borrador que pasa la validación, con una etiqueta SemVer
  que el workflow no haya usado antes.
- Una versión publicada es inmutable. Los cambios posteriores del borrador no
  la alteran: para cambiar lo que recibe el SDK, publica una versión nueva.
- El SDK recibe solo la versión publicada más reciente de cada workflow no
  archivado. Los borradores nunca salen del servidor.
