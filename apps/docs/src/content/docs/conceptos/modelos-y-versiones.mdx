## Reglas

- Una versión publicada es inmutable.
- Su archivo no se puede sobrescribir ni reemplazar: un cambio en el modelo se
  sube como una versión nueva.
- Cada versión tiene una etiqueta SemVer (por ejemplo, `1.0.0`) única dentro
  de su modelo.
- El servidor rechaza un archivo que no es un modelo TensorFlow Lite válido.
- Solo se puede eliminar una versión que ningún borrador de workflow usa.
- El SDK instala una versión solo si su SHA-256 coincide con el publicado, y
  no vuelve a descargar una versión que ya tiene instalada.
