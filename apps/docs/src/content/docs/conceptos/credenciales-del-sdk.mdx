Un administrador genera la credencial en el dashboard para una aplicación
activa. El secreto empieza por `ayni_sk_`. El listado de credenciales muestra
solo el prefijo, el estado (`active` o `revoked`) y las fechas.

:::caution
Si pierdes el secreto no se puede recuperar. Genera una credencial nueva y
revoca la anterior.
:::

## Reglas

- El secreto se muestra una sola vez, al generar la credencial.
- El servidor guarda solo su hash SHA-256 y un prefijo para reconocerla en el
  listado; nunca vuelve a mostrar el secreto.
- Una credencial pertenece a una sola aplicación y solo sincroniza los
  recursos de esa aplicación.
- Una aplicación archivada no acepta credenciales nuevas.
- Una credencial revocada ya no autentica ni sincroniza recursos nuevos.
- Revocar una credencial no borra workflows, modelos ni versiones del servidor,
  y no borra los recursos ya instalados en los dispositivos.
