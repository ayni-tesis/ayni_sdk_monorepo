Requests cancellation of an active execution.

The identifier is provided to run's onExecutionStarted callback. Cancellation takes effect before the next node begins; an in-progress model inference is allowed to finish. Throws WorkflowErrorCategory.executionNotFound when the execution has ended or the identifier is unknown.

Implementation

void cancelExecution(String executionId) {
  final execution = _activeExecutions[executionId];
  if (execution == null) {
    throw const WorkflowError(WorkflowErrorCategory.executionNotFound);
  }
  execution.cancelled = true;
}
