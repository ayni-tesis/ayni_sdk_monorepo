syncTimeout

syncTimeout property

Duration syncTimeout
final

The longest a sync call may take. Defaults to 30 seconds.

When it elapses, sync stops its downloads and returns a SyncResult with SyncStatus.error and no resources. The inventory keeps the versions installed before that sync, so run keeps using them. A later sync starts once the abandoned one has finished.
