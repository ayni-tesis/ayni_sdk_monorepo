ModelArtifactInstaller

ModelArtifactInstaller class

Installs integrity-verified model artifacts for offline workflow execution.

Each model version is stored as <modelId>/<modelVersionId>.tflite with a .json metadata file under storageDirectory. AyniSdk.sync and AyniSdk.run use it internally; apps do not need to call it.
